## Important Findings

The scan identified **23 open TCP ports** on `192.168.1.9`.

The highest-risk services observed were:

* **Port 23 – Telnet:** Uses an insecure, unencrypted protocol.
* **Ports 512–514 – rexec/rlogin/shell:** Legacy remote-access services.
* **Port 1524 – Bindshell:** Provides an intentionally vulnerable root shell in Metasploitable.
* **Port 3306 – MySQL:** Database service exposed over the network.
* **Port 5432 – PostgreSQL:** Database service exposed over the network.
* **Port 5900 – VNC:** Remote graphical access service.
* **Ports 139/445 – SMB:** File-sharing services increase the attack surface.
* **Ports 80/8180 – HTTP/Tomcat:** Web services using old software versions.

## Security Analysis

The target machine has a large number of exposed services. Several services use old software versions or insecure legacy protocols.

The most serious issue is the **Metasploitable root shell on port 1524**, which is intentionally present for cybersecurity training. In a real production system, such a service would represent a critical security risk.

The exposed FTP, Telnet, database, SMB, VNC and legacy remote-access services also increase the system's attack surface.

For a real system, unnecessary services should be disabled, software should be updated, network access should be restricted, and encrypted protocols should be preferred.

## Conclusion

The Nmap scan successfully identified **23 open TCP ports and their associated services** on the Metasploitable test machine at `192.168.1.9`. Service-version detection identified several outdated services, while OS detection identified the target as a Linux-based system.

The results demonstrate how network scanning can be used to identify exposed services and potential security risks. Since this was an intentionally vulnerable Metasploitable laboratory machine, the findings are suitable for cybersecurity learning and testing.

Unnecessary services should be disabled, exposed services should be properly secured, and systems should be regularly updated and monitored.
